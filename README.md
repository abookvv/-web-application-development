# Экспедитор — сайт (учебный проект)

Итоговый проект по дисциплине «Разработка веб-приложений».

Чистые HTML, CSS и JS, без сервера. Открыть можно двойным щелчком по `index.html`.

## Как устроена страница

1. В `<body>` указываем код страницы и роли: `data-page="orders" data-roles="logist,manager"`.
2. Пустой `<header id="app-header"></header>` — шапку и меню рисует `js/app.js` сам, по роли.
3. Внизу подключаем `js/data.js`, потом `js/app.js`, потом свой скрипт.
4. Если не вошли — отправит на вход. Если роли нельзя на страницу — отправит на её главную.

## Что даёт `Exp` (из `js/app.js`)

- `Exp.user` — кто вошёл: `{ login, name, short, role }`, роль: `logist`, `manager`, `admin`.
- `Exp.load('orders')` / `Exp.save('orders', list)` — читать и сохранять данные (localStorage, иначе `data.js`).
- `Exp.resetData()` — вернуть демо-данные к исходным (выполнить в консоли перед показом).
- `Exp.crumbs([['Заявки', 'orders.html'], ['Санкт-Петербург → Москва']])` — хлебные крошки в `<nav id="crumbs">`.
- `Exp.money(88000)` → `88 000 ₽`, `Exp.date('2026-10-21')` → `21.10.2026`.
